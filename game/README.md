# SpriteForge Hill Climb — 2D Vehicle Physics Sandbox

A 2D physics-based hill climbing game demo built to showcase real-time vehicle asset generation from SpriteForge.

## Overview
This game demonstrates how 2D vehicle sprite sheets and chassis generated by SpriteForge are imported directly into a live, playable game loop with physics, suspension, terrain deformation, and gameplay mechanics.

## Architecture & Modules
- **Physics Core (`src/physics.js`):** 2D spring/raycast suspension, chassis rigid-body dynamics, wheel angular velocity, air-tilt balancing, and slope friction.
- **Terrain Generator (`src/terrain.js`):** Infinite procedural rolling hills using multi-octave sine/Perlin noise math with chunked rendering.
- **Asset Importer (`src/importer.js`):** Direct bridge connecting to SpriteForge's `/api/sprites` endpoint to load generated car bodies and attach physics wheels.
- **Game Engine & Loop (`src/game.js`):** Camera tracking, state machine (Menu, Driving, Flipped, Out of Fuel), HUD (Distance, Speed, Fuel Gauge, Coins).
- **Audio & FX (`src/particles.js`, `src/audio.js`):** Dirt spray, exhaust puffs, tire skid marks, and Web Audio API engine synthesized audio.

| Mid-Air Tilt Left | `A` / `ArrowLeft` | Left Pedal Button |
| Mid-Air Tilt Right | `D` / `ArrowRight` | Right Pedal Button |
| Restart Run | `R` | Reset Button |
